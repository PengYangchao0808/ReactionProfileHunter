## 9. 结论与建议

1. **引入 Shermo 热力学校正后，Winner 从 SP-REF 变为 SP-1**，
   热力学校正的引入使 SP-1 在反应能量预测上的精度优势（ΔG_rxn MAE 0.91）被充分体现

2. **SP-1 (wB97M-V/def2-TZVPP) 是 Shermo 校正后的最优选择**：
   综合 MAE 1.63 kcal/mol，ΔG_rxn 近乎完美，ΔG‡ 保守偏高 ~2.4 kcal/mol

3. **SP-3 (wB97X-2) 虽然纯电子能阶段表现最优，但在热力学评估中 ΔG_rxn 偏差偏大（3.29 kcal/mol）**

4. **SP-REF (DLPNO-CCSD(T)) 作为参考方法仍然必要**，但 SP-1 作为实用替代已足够可靠

5. **建议在 Phase 2 几何优化基准测试中**同时使用 SP-1 作为 SP reader，验证几何+热力学的整体精度
