# RPH V7.1 升级报告：紧凑数据集与特征体系

**版本**: V7.1  
**日期**: 2026-05-25  
**基于**: RPH V2.1.1 / rph_features 模块  
**输入数据**: `data/processed_rph_v6_thermo/stage1_branch_yield_dataset.csv` (20 rows × 217 cols)

---

## 1. 升级概述

V7.1 是对 V6→V7 rph_features 模块扩展的进一步深化。在审核发现当前特征集未能充分覆盖 yield 失败和 DR 失败根因后，V7.1 在三个方向进行了增强：

| 方向 | V6 基线 | V7 初步 | V7.1 增强 |
|------|---------|---------|----------|
| 特征集数量 | 无正式定义 | F0-F4 (4套) | F0-F5 (5套) + 9 族完整度体系 |
| Yield 特征维度 | ~7 features | ~7 | **20 features** (扩增 S1 activation/preorganization/tether) |
| DR 特征维度 | ~9 features | ~9 | **25 features** (扩增 delta tether/flexibility/preorganization) |
| 条件交互 | 无 | 无 | **15 对交互项** |
| 完整度诊断 | 无 | 缺失率单特征 | **9 族 per-reaction 评分** |
| 视图类型 | 3 个 (V5) | 4 个 | **6 个** (新增 failure-aware + paired-branch) |
| Low-support 标记 | 无 | 无 | **自动标记 support_count < 2** |
| 特征筛选 | 通用单目标 | 通用单目标 | **yield/DR 双头分离筛选** |

**扩增逻辑 (V7 → V7.1)**:

产率本质上受两个因素控制：
1. **活化难度** — 反应物需要多少能量才能跨过能垒。`s1_dG_act`、`s1_Keq_act` 直接量化这一难度。V6 训练失败分析显示 RXN_c29a9b9a (yield=0.65 pred=0.155) 的产率预测完全失败，根因之一就是缺少活化难度描述符。
2. **productive conformer 的可用性** — 在构象系综中，有多少比例处于"准备好的"反应构象。`s1_productive_population`、`s1_d_reactive_mean` 量化了这一比例。若大部分构象需要额外扭转才能进入 TS，产率自然降低。
3. **tether 的局部柔性** — 柔性 tether 使反应位点更容易接近，降低有效活化能。`s1_tether_rg_mean` (回转半径，量化 tether 紧凑程度) 和 `s1_tether_torsion_H_sum` (扭转熵，量化柔性) 捕捉了这一效应。
4. **leaving group 几何** — C-O 键长、α-H 距离、二面角等局部几何参数影响 DMDO 环氧化步骤的效率，进而影响环氧中间体的生成速率。

**扩增逻辑 (V7 → V7.1)**:

DR / 选择性本质上由两个 branch 之间的差异化决定：
1. **branch-delta 预组织差异** — 两个 branch 的 reaction site 距离分布差异 (`delta_s1_d_reactive_mean/std/q10/q90`) 直接决定哪个 branch 在构象空间中更接近 TS 几何。若两个 branch 的预组织程度相似，DR 接近 1:1。
2. **branch-delta tether 柔性差异** — 两个 branch 的 tether 局部环境不同（扭转自由度、回转半径），影响各自的有效活化熵。V6 训练失败分析中 RXN_a2b7acff (true DR=60:40, pred=94:6) 是 DR 严重失败的典型案例——模型缺少立体/柔性描述符，把中等选择性误判为强 selective。
3. **branch-delta 局部几何** — 不同 branch 中 leaving group 的几何环境差异 (`delta_s1_d_C_O_lg`, `delta_s1_tau_CH_C_O`) 影响环氧化步骤的 branch 选择性。
4. **GEDT 差值绝对值** (`abs_delta_s2_gedt_value`) — V7.1 新增。电子密度转移差异的绝对值对 near-1:1 DR 区域的区分尤其重要。V6 模型对 RXN_f0ec0c2e (true DR=52:48, pred=65:35) 的失败部分源于无法捕捉"电子差异很小"的信号。

| `LA_intensity × major_s1_Nconf_eff` | `LA_intensity_x_major_s1_Nconf_eff` | Lewis 酸对有效构象数的调制 |

| `LA_intensity × major_s1_E_span` | `LA_intensity_x_major_s1_E_span` | Lewis 酸对构象能量跨度的调控 |

| `temperature_K × major_s1_Sconf` | `temperature_K_x_major_s1_Sconf` | 温度对构象熵的调控——低温放大构象选择性 |

## 3. 特征缺失根因分析

### 3.1 完全缺失族 (0% cell completeness)

#### S1_activation — `s1_dG_act`, `s1_Keq_act`, `delta_s1_dG_act`, `delta_s1_Keq_act`

**根因**: 这些特征依赖 S3 完成后对 S1→TS 路径的 Shermo 热力学计算。当前 V6 数据集的 `stage1_branch_yield_dataset.csv` 中这些列存在于 schema 但所有 20 行的值均为 NaN。

**上游依赖链**:
```
S1 构象搜索 → S3 TS 优化 → S3 Shermo 计算 TS/S1 Gibbs → s1_dG_act = G_TS - G_S1
```
若 S3 的 Shermo 步骤未对 S1 反应物运行（仅对 TS/intermediate/product 运行），则 `s1_dG_act` 无法计算。

**修复路径**: 在 S3 Shermo 流程中增加对 S1 构象全局最小值的单点能+频率计算，然后将 Gibbs 自由能回填至 S1 目录。

#### S1_tether_flexibility — `s1_tether_*` 系列

**根因**: 这些特征来自 `torsion_flexibility` 提取器 (P2)，需要对 S1 所有构象计算 tether 区域中每个可旋转键的扭转角分布。当前这些列存在于 schema 但无一有值。

**上游依赖链**:
```
S1 conformer ensemble → RDKit rotatable bond identification → torsion angle scan per conformer → H(θ) entropy → s1_tether_torsion_H_sum
```
若 S1 的 XYZ 文件丢失、或 product SMILES 无法解析（无法确定 tether 原子），则提取器返回 NaN。

**修复路径**: 检查 S1 构象目录中是否有完整的 conformer XYZ 集合，以及 product_min.xyz 中的 atom mapping 是否正确。

#### S1_local_geometry — `s1_d_C_O_lg`, `s1_tau_*`, `s1_angle_*` 等

**根因**: 这些特征来自 `step1_activation` 和 `geometry` 提取器，需要对 S1 全局最小构象进行几何分析（键长、键角、二面角）。提取器需要知道 forming bonds 和具体的原子索引。

**上游依赖链**:
```
S1 global minimum XYZ → forming_bonds atom indices → distance/angle/dihedral calculation
```
若 forming bonds 未正确解析，或 0-based/1-based index 转换出错，提取器无法定位正确的原子。

**修复路径**: 验证 forming_bonds_resolver 对每个反应的输出，确保原子索引正确映射到 S1 构象的 XYZ 文件。

### 3.2 部分缺失族

#### S1_conformational_population (57% completeness)

`major_s1_Hpop`, `Hpop_per_rotbond`, `wmax`, `N90`, `rank1_rank2_gap` 等部分行有值，部分缺失。缺失原因：`conformational_population` 提取器需要 S1 conformer_energies.json + conformer_thermo.csv 同时存在，且至少要有 2 个以上构象。少数反应的 S1 只产生了 1 个构象（或 conformer_energies.json 为空），此时所有 population 描述符均为 NaN。

### 3.3 可用族

- **S1_conformational_energy (93%)**: 基础构象能量描述符大部分可用。5% 缺失来自个别 conformer_energies.json 缺失导致的 E_avg_weighted 等加权量 NaN。
- **S2_electronic (83%)**: CDFT/GEDT 电子描述符大部分可用。17% 缺失主要来自 minor branch 的 electronic features——部分反应的 minor branch 未完成 S2 扫描，导致 `minor_s2_*` 列 NaN。
- **S1_topology (92%)**: tether_length、rotatable_bond_count 等拓扑特征基本可用。个别反应的 product SMILES 无法解析时缺失。
- **condition (100%)**: 实验条件信息完全可用——来自 reaxys 原始数据的手工整理。

## 4. 交互特征说明

V7.1 的 `interaction_features.py` 从 `FEATURE_SET_F5_INTERACTION_PAIRS` 中定义的 15 对列名，计算逐元素乘积作为新特征。

**计算方法**: `interaction_value = col_a_value × col_b_value`

若两列均为有效数值，则计算；若任一列 NaN，则交互项为 NaN。当前 V6 数据上，15 对全部成功计算（所有条件列和 S2 电子列均有值），输出为 `stage1_branch_yield_with_interactions.csv`。

**适用范围**: 交互项仅用于产率 (yield) head——它们捕获了"条件如何调制底物的化学反应性"。DR head 中条件效应较弱，交互项暂不进入 F3 选择体系。

## 5. 新增视图与辅助输出

### 5.1 compact_failure_aware_view (16 rows × 64 cols)

保留 `failure_aware_trainable` 行，包含 major branch features + minor branch missingness 元数据 (`minor_branch_feature_status`, `missing_reason`, `_missing` indicator 列) + DR targets。

**用途**: 当 minor branch 的计算数据缺失时，将"缺失"本身作为信息——某些底物确实只走一个 branch，缺失不是随机噪声而是化学信号。

### 5.2 compact_paired_branch_view (11 rows × 165 cols)

保留 `paired_feature_trainable` 行，包含 major/minor/delta/abs_delta 全列 + DR targets。

**用途**: 用于训练 branch-delta 模型，需要两个 branch 的计算特征同时可用。11 行中 V6 模型可学习 DR 的 branch 间差异。

### 5.3 low_support_reactions.csv

按 `reaction_id` 分组计数条件数 (`support_count`)，标记 `low_support = support_count < 2`。

**当前 V6 数据**: 3 个 reactions 被标记为 low-support (单条件样本)。LORO CV 下这些 reaction 无法学习条件趋势，应单独评估而不计入 R²。

### 5.4 feature_benchmark_comparison.csv

yield/DR split selection 的输出，列出每个候选特征是否被 yield head 和 DR head 保留，以及两者 MI scores 的差异。

**当前 V6 数据**: 仅 1 个特征同时被 yield 和 DR head 保留——说明两个 head 需要的化学信息维度高度不同，合并建模是不合理的。

## 7. 后续建议

### 优先级 1: 补足上游缺失特征

当前 **S1_activation、S1_tether_flexibility、S1_local_geometry** 三个族为 0% cell completeness，这直接限制了 yield 和 DR 模型的解释力。

1. **S1_activation** — 在 S3 Shermo 流程中增加对 S1 反应物构象的 Gibbs 自由能计算，回填 `s1_dG_act`/`s1_Keq_act`。
2. **S1_tether_flexibility** — 修复 `torsion_flexibility` 提取器的 product SMILES 解析路径，验证 S1 conformer ensemble 完整性。
3. **S1_local_geometry** — 验证 `forming_bonds_resolver` 对每个 reaction 的原子索引映射，修复 `step1_activation` 提取器的输入路径。

### 优先级 2: 数据扩容

当前仅 16 个 `structured_trainable` 行、9 个 reaction groups，对模型稳定性和泛化验证严重不足。建议：
- 增加更多底物类型（不同 tether 长度、不同 auxiliary）的 RPH 计算
- 每个 reaction 保证 ≥3 个条件，消除单点样本

### 优先级 3: 条件-响应非线性建模

V7.1 的 15 对交互项是线性乘积形式。下一版本可考虑：
- 二次项 (`LA_intensity²`)
- 分段编码 (`temperature_bin × LA_intensity`)
- 组合条件编码 (`condition_profile` embedding)
