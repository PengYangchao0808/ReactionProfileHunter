## 2. S1_conformational_energy 构象能量 (32 列)

**数据来源**: S1 finalDFT → `conformer_energies.json` (仅 1-2 构象)  
**完整度**: major=100%, minor/delta/abs_delta=75% (5 个反应 minor 缺失)  
**核心问题**: 系综太小 (1-2 构象) → E_span, Sconf 等统计量无统计意义 → 需要改用 GFN2 全系综 155 构象

### 2.1 能量分布

| 特征 | 含义 | 化学意义 |
|------|------|---------|
| `*_s1_E_span` | 最高-最低构象能量差 (kcal/mol) | PES 的起伏程度。span 大 → 构象能量分散。 |
| `*_s1_E_avg_weighted` | Boltzmann 加权平均能量 (kcal/mol) | 构象系综的"有效能量"。 |
| `*_s1_E_std` | 构象能量标准差 (kcal/mol) | 多构象 (>5) 时比 span 更稳健。 |
| `*_s1_E_variance` | 能量方差 ((kcal/mol)²) | 对尾部离群更敏感。 |
| `*_s1_G_avg_weighted` | Boltzmann 加权 Gibbs 自由能 | E_avg 减去 T×Sconf。构象很少时与 E_avg 几乎相同。 |

### 2.2 构象计数与熵

| 特征 | 含义 | 化学意义 |
|------|------|---------|
| `*_s1_Nconf_eff` | 有效构象数 = exp(Sconf/R) | **当前仅 1.0-2.0。** |
| `*_s1_Nconf_total` | 总构象数 (CREST 原始输出) | finalDFT 筛选后的构象数。 |
| `*_s1_Sconf` | 构象熵 (cal/mol/K) | Sconf = -R×Σ p_i ln p_i。 |

### 2.3 关键相关性 (V6 实测)

| 特征 | ρ vs yield (target_scale) | ρ vs DR (target_comp) |
|------|:---:|:---:|
| `major_s1_E_span` | -0.367 | -0.523 |
| `major_s1_E_avg_weighted` | +0.585 | +0.492 |
| `major_s1_Nconf_eff` | -0.274 | **-0.564** |
| `delta_s1_E_span` | **+0.701** | -0.035 |

## 3. S1_conformational_population 构象种群 (24 列)

**数据来源**: 同 S1_conformational_energy → `conformer_energies.json` (仅 1-2 构象)  
**完整度**: major=100% (wmax/Hpop/N90)；rank1_rank2_gap=25% (需 ≥2 构象)；Hpop_per_rotbond=0%  
**核心问题**: 系综太小 — wmax 几乎恒为 1.0, Hpop≈0, N90=1

### 3.1 种群分布特征

| 特征 | 定义 | 物理意义 |
|------|------|---------|
| `*_s1_wmax` | 最大 Boltzmann 权重 = max(p_i) | wmax=1.0 → 被锁定；wmax=0.5 → 两个构象平分。 |
| `*_s1_Hpop` | Shannon 种群熵 = -Σ p_i ln p_i | 无量纲信息熵。 |
| `*_s1_Hpop_per_rotbond` | Hpop / N_rotatable_bonds | 消除分子大小对 Hpop 的干扰。**当前全为 NaN。** |
| `*_s1_N90` | 达到 90% 累计种群所需的最小构象数 | N90=1 → 垄断；N90≥3 → 竞争性市场。 |
| `*_s1_rank1_rank2_gap` | 全局 min 与次低能量的间隙 (kcal/mol) | **最基础的种群信号。当前仅 25% 有值。** |

### 3.2 种群特征推导链

```
rank1_rank2_gap → 控制 wmax → 决定 Hpop (= Sconf/R)
                              → 决定 Nconf_eff (= exp(Hpop))
                              → 决定 N90
```

## 4. S1_preorganization 构象预组织 (26 列)

**数据来源**: S1 finalDFT conf_*.xyz → forming_bonds 原子间距离 + Boltzmann 权重  
**完整度**: major=100%, minor/delta=75%  
**核心问题**: 测量的是 product 中已形成的 C-C 键长 (~1.54 Å)，而非 precursor 中反应前的原子接近程度。`productive_population` 恒为 1.0。

### 4.1 距离分布

| 特征 | 定义 | 物理意义 |
|------|------|---------|
| `*_s1_d_reactive_mean` | forming bond 原子间加权平均距离 (Å) | **实际测量**: product 中 C-C 键长 (1.53-1.56 Å)。与 DR 的 ρ=**+0.883**。 |
| `*_s1_d_reactive_std` | 加权标准差 (Å) | 构象间键长的变异程度。当前极低。 |
| `*_s1_d_reactive_q10` | 加权 10 百分位距离 (Å) | "最紧密的构象有多紧"。 |
| `*_s1_d_reactive_q90` | 加权 90 百分位距离 (Å) | "最松散的构象有多松"——ρ=**+0.943** (最强单一特征)。 |
| `*_s1_productive_population` | 距离 < 3.0 Å 的 Boltzmann 权重和 | **恒为 1.0**——无区分度，应删除。 |

### 4.2 关键相关性 (V6 实测)

| 特征 | ρ vs yield | ρ vs DR |
|------|:---:|:---:|
| `major_s1_d_reactive_q90` | — | **+0.943** |
| `major_s1_d_reactive_mean` | — | +0.883 |
| `delta_s1_d_reactive_q90` | — | **-0.759** |

### 4.3 命名问题

当前 `s1_d_reactive_*` 实际上测量的是 **产物几何中的 C-C 键长**，应重命名为 `s1_post_bond_length_*`。真正的"预组织"应测量 precursor 构象系综中对应原子的反应前距离（预期 3-6 Å）。

## 8. S2_electronic S2 电子结构 (26 列)

**数据来源**: S2 retro scan → single-point DFT → CDFT/GEDT 分析  
**完整度**: major=100%, minor/delta/abs_delta=75%

> **注意**: 尽管命名为 "S2"，这些特征实际读取的是 **S3 输出的 ts_fchk**（S3 优化后的 TS 结构的 wavefunction）。S2 产生 ts_guess，但电子结构分析在 S3 优化后的最终 TS 结构上进行。

### 8.1 CDFT 全局反应性指标

| 特征 | 物理含义 | 化学意义 |
|------|---------|---------|
| `*_s2_eps_homo` | HOMO 能级 (eV) | 分子的给电子能力。HOMO 越高 → 亲核性越强。 |
| `*_s2_eps_lumo` | LUMO 能级 (eV) | 分子的受电子能力。LUMO 越低 → 亲电性越强。 |
| `*_s2_mu` | 化学势 μ ≈ (HOMO+LUMO)/2 (eV) | μ 越负 → 分子越亲电。 |
| `*_s2_eta` | 化学硬度 η = (LUMO−HOMO)/2 (eV) | η 大 → "硬" → 反应性低 → 需要更强的活化。 |
| `*_s2_omega` | 亲电指数 ω = μ²/2η (eV) | ω 大 → 强亲电 → 反应快。 |

### 8.2 GEDT 电荷转移

| 特征 | 物理含义 | 化学意义 |
|------|---------|---------|
| `*_s2_gedt_value` | 全局电子密度转移量 GEDT (e) | 从 dipolarophile 向 dipole 的净电子转移量。 |

### 8.3 关键相关性 (V6 实测)

### 12.3 命名歧义

S3 中的 "intermediate" 与 S2 中的 "intermediate" 不是同一文件：

当前 S4 收到的是 S2 的原始版本（通过 `result.intermediate_xyz`），而非 S3 优化后的版本。

### 13.2 缺口详细说明

#### Gap 1: NBO E(2) 供受体相互作用能 ❌ 严重

- **当前状态**: `nbo_e2` 提取器代码完整（模板匹配、解析器均在 `rph_features/rph_features/nbo/e2_parser.py`），但 `extract()` 方法在 Phase A 仅返回空字典 + job_specs
- **影响**: NBO 供体→受体 E(2) 稳定化能完全缺失。这是量化 orbital 相互作用的最重要工具之一——可解释为何某些 reaction path 有利
- **上游条件**: S3 中 `reactant_opt.enable_nbo: true` 必须开启；NBO 文件 `*.37` 从 S3 reactant_opt 目录收集至 S4
- **修复思路**: 在 Phase C 模式下，`nbo_e2.extract()` 调用现有的 `find_nbo_e2_section()` → `parse_nbo_e2_table()` → `match_templates()` 管线

#### Gap 2: IRC 反应路径数据 ❌ 中等

- **当前状态**: `irc_driver.py` (430 行) 完整实现了 IRC 计算——产生 `IRCResult`(forward_endpoint, reverse_endpoint, forward_path, reverse_path, n_points, energies)
- **S3 中 IRC 的状态**: `verify_irc` 默认为 `False`；即使执行，IRC 结果也不打包进 `TransitionAnalysisResult`
- **可提取特征**:
  - `irc.n_points_forward/reverse` — 路径点数
  - `irc.barrier_forward/reverse_kcal` — 反应能量曲线
  - `irc.path_length_forward/reverse` — 几何变化量
  - `irc.endpoint_rmsd_to_product/reactant` — 端点验证
- **修复思路**: (1) 在 S3 结果中包含 IRC 路径数据；(2) 创建 `irc_validation` 提取器

#### Gap 3: Hessian 矩阵 / 力常数 ❌ 中等

- **当前状态**: `ts_quality` 仅提取虚频计数和绝对值 (`ts.n_imag`, `ts.imag1_cm1_abs`)，不读取模式矢量和力常数矩阵
- **可提取特征**:
  - `hess.eigenvalues` — 所有频率谱
  - `hess.imag_mode_overlap_forming` — 虚频模式矢量与 forming bonds 的重叠
  - `hess.force_constant_avg` — forming bond 原子间平均力常数
  - `hess.zpe_kcal` — 零点能
- **修复思路**: 扩展 `ts_quality` 或新建 `hessian_quality` 提取器

#### Gap 4: QC 收敛元数据 ❌ 低-中

- **当前状态**: S3 的 `QCOptimizationResult` 包含 `converged`, `method_used`, `failure_kind`, `rescue_route`，但这些不进入 FeatureContext
- **可提取特征**:
  - `s3.method_used` — Berny 或 QST2 (区分直接收敛 vs 救援收敛)
  - `s3.max_force`, `s3.rms_force` — 最终收敛力
  - `s3.max_displacement`, `s3.rms_displacement` — 最终收敛位移
  - `s3.opt_cycles` — 优化循环数
  - `s3.rescue_attempted` — 是否触发救援策略
- **修复思路**: 在 `sp_matrix_metadata.json` 中持久化收敛元数据；新建 `s3_qc_metadata` 提取器

#### Gap 5: 片段能量 ❌ 低

- **当前状态**: `SPMatrixReport` 有 `e_frag_a_ts`, `e_frag_b_ts`, `e_frag_a_relaxed`, `e_frag_b_relaxed` 字段，但当前值均为 0.0 (占位符)
- **可提取特征**: `asm.frag_a_distortion`, `asm.frag_b_distortion`, `asm.interaction_energy`
- **修复思路**: 实际上这些值应来自 S3_PostQCEnrichment (由 `asm_enrichment` 提取)。`SPMatrixReport` 中的占位字段可清理。

#### Gap 6: S3 优化后的 intermediate ❌ 低

- **当前状态**: S3 的 `intermediate_xyz` (优化后的中间体几何) 在 PipelineResult 中被丢弃
- **可提取特征**: `s3_int_opt.natoms`, `s3_int_opt.rg`, `s3_int_opt.rmsd_to_guess` (与原始 S2 guess 的偏差)
- **修复思路**: 在 PipelineResult 中增加 `intermediate_xyz_from_s3` 字段并在 FeatureContext 中暴露

### C. S3 贡献评估

尽管 S3 是管线中计算最昂贵的步骤（DFT TS 优化 + L2 SP + 频率分析 + Shermo），其产出的计算化学信息在特征提取中的利用率严重不足：

| 指标 | 数值 |

| S3 计算产物种类 | ~15 类 (文件/数据结构) |
| S3 产物中有特征提取覆盖的比例 | 8/15 = **53%** |
| 有覆盖的产物中空运行的比例 | 3/8 = **38%** |
| 实际产出特征中 S3 来源的比例 | ~25/~75 = **33%** |
| 最大单一缺口 | NBO E(2) — 代码完整但未激活 |

**结论**: 特征提取严重依赖 S1 构象搜索产物（50+ 列），而管线中最昂贵的 S3 步骤产出的丰富物理化学信息（NBO 相互作用、IRC 路径、Hessian 矩阵、QC 收敛元数据）几乎未被利用。这导致特征空间严重偏向"底物性质"而缺乏"反应关键过程"的描述。
