Quality Gates (Mandatory)

S2 Quality Gate

A LiCl-enabled scan is accepted only if:

ConditionThreshold
Forming bonds contain no Li/ClMust pass
Li–Cl distance≤ 3.5 Å
Li–O distance (nearest)≤ 2.6 Å
Cl–reaction center distance≥ 3.2 Å
Coordination site switchForbidden

S3 Quality Gate

A LiCl-enabled TS is accepted only if:

ConditionThreshold
Chemically relevant imaginary modes (after excluding LiCl floppy modes)≥ 1
Dominant mode projection onto forming bonds≥ 0.35
LiCl motion contribution≤ 0.25
IRC for flagged TSRequired if projection < 0.50

Validation Gates

GateWhat It ValidatesCriteria
A · Geometry Sanity LiCl actually coordinates Stable Li–O contact formed; LiCl not drifted away (Li–Cl ≤ 3.5 Å, Li–substrate ≤ 4.0 Å); Cl not at reaction center (≥ 3.2 Å)
B · Reaction Identity Organic reaction unchanged SMARTS-derived forming bonds match no-LA run; Li/Cl never in forming-bond list; TS imaginary mode is organic reaction mode
C · ML Usefulness Features add value LiCl features non-constant across dataset; improve LORO/nested CV over no-LA baseline; improvement vanishes under shuffled-target control
D · Physical Benchmark Directionally correct On 2–3 representative reactions: compare no-LA vs LiCl vs one real LA at intermediate/product level. Do NOT require exact energy match. Require same direction of coordination/preorganization effect.
