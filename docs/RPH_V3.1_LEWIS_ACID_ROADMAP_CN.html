🔧 V3.0.0 各模块功能详解

1. 编排器 — orchestrator.py (3641行)

ReactionProfileHunter 类是整个流水线的总指挥，采用"编排器只调度不干活"的设计模式。
方法行号功能数据流

_resolve_forming_bonds_for_s2()668 5级成键解析链：cleaner→atom_map→S0→SMARTS→deferred 产物几何验证→传递给 S2 scan 和 S3 优化

main()2048 CLI 参数解析: --smiles, --output, --config, --reaction-type, --skip-steps argparse → config merge → run_pipeline()

2. S0 — 机理分类器 (可选)

构建有向无环图 (DAG) 表示反应机理，识别环加成模式。跳过时 S2 回退 SMARTS 自动检测。
文件类/方法功能

3. S1 — 锚定/构象搜索

UCE v3.1 双阶段构象引擎：GFN0→GFN2→DFT OPT/SP。分子自治架构，每个分子独立目录。
组件功能关键代码
AnchorPhase.run() 接收 {name: SMILES} dict，为每个分子执行锚定 handler.py:165 → 并行/顺序调度各个分子
ConformerEngine.run() CREST 构象搜索 → xTB GFN0 粗筛 → GFN2 精筛 → DFT OPT/SP engine.py: 双阶段 UCE v3.1
SmallMoleculeCache 小分子 (≤10 重原子) 跳过 CREST，直接从缓存复用或简单优化 small_molecule_cache.py: key = {formula}_{canonical_smiles}
Protocol 系统 ext/full/lite/zero 协议，控制构象搜索的采样深度 protocols.py + config step1.conformer_search

输出目录结构：

  ├── xtb/            # xTB 阶段 (stage1_gfn0/ + stage2_gfn2/)

  ├── prescan/        # full 协议快速 SP 预筛选
  ├── fastsp/         # full/lite 协议快速 SP 筛选
  └── finalDFT/       # DFT OPT+SP (conformer_thermo.csv, *.fchk, *.log)

形成键解析链 (7种来源)

_resolve_forming_bonds_for_s2() 按优先级依次尝试，直到成功：
  1. S1 atom_map_xyz full notation → forming_bonds_full_notation
  2. S0/S1 atom-map annotations → SMILES 映射 + XYZ 映射
  3. S0 mechanism_graph primary edges → 通过 XYZ 映射
  4. S0 mechanism_summary.json → 原始 forming_bonds 字段
  5. SMARTS auto-detection → SMARTSMatcher.find_reactive_bonds()
  6. Deferred low-confidence bonds → S0 标记低置信度
  7. Geometry-difference inference → 产物 vs TS 图差异分析

⚠️ 风险登记表

风险概率影响缓解措施
SMARTS 被 Li–O 成键感知误扰 低 高 从规范 SMILES 而非 XYZ 构建分子
Li–Cl 解离误认为成键 中 高 强制 SMARTS fallback；添加物原子硬过滤
CREST 构象搜索中 LiCl 解离 中 中 NCI mode + wall potential + 弱 Li–O 约束
xTB 扫描中 LiCl 漂移 中 中 监测 Li–O 轨迹；解离时标记降级
TS 优化器追逐 LiCl 而非反应 中 中 验证虚频模式投影；排除添加物模式
LiCl 配位到错误位点 中 低 CREST ensemble 找全局最小；S1 后验证
检查点身份混淆 (LA-on vs LA-off) 低 高 hash 含规范 SMILES + 完整 LA 配置，不含几何 SMILES
ML 特征无改进 低 中 验证门 C: LORO/CV 必须有改进；shuffle 控制下消失
真实 LA 被视为线性校正 确定 低 描述符作为 ML 特征(含交互项)，非 ΔG‡ 修正器

✅ 验证门 A–D

门验证内容标准
A · 几何合理性 LiCl 实际配位 稳定 Li–O 接触；LiCl 未漂移 (Li–Cl ≤ 3.5, Li–底物 ≤ 4.0)；Cl 不接近反应中心 (≥ 3.2)
B · 反应身份 有机反应不变 SMARTS 成键与无 LA 运行一致；Li/Cl 永不在成键列表；TS 虚频为有机反应模式
C · ML 有效性 特征增加价值 LiCl 特征在数据集中不恒定；LORO/CV 优于无 LA 基线；shuffle 控制下改进消失
D · 物理基准 方向正确 2-3 个代表性反应：比较无 LA vs LiCl vs 一个真实 LA (中间体/产物层面)。不要求能量精确匹配。要求配位/预组织效应方向一致。
